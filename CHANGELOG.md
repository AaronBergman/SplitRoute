# Changelog

## v0.1 — 2026-08-21

Initial experimental release.

- Added same-subnet IPv4 split routing with Wi-Fi as the connection source and
  Ethernet as the outbound path.
- Added a privileged safety watchdog with rollback and prompt-free repair.
- Added a menu-bar controller and dashboard.
- Added an IPv4-aware download/upload speed test with route-share reporting.
- Added a ready-to-install drag-to-Applications DMG.

This version has not been tested extensively. No promise is made that it works
well—or at all.
